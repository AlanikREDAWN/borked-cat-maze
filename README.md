It’s a simple maze game! Or is it? Try to figure out where of the WASD keys send you!
There are three difficulties, with the size of the maze increasing the more the difficulty increases.
The part of this project I'm most proud of is the random maze generator, which I still think is super cool, not to mention fun to watch!



Made for Hack Club's Borked Game Jam
